# Contribuindo com o Luminous

Obrigado pelo interesse no projeto.

O Luminous encontra-se em fase inicial de concepção.

Neste momento, contribuições são especialmente bem-vindas nas áreas de:

- educação pública;
- acessibilidade;
- experiência do usuário;
- segurança;
- privacidade;
- arquitetura;
- inteligência artificial educacional;
- funcionamento offline;
- interoperabilidade entre sistemas educacionais.

## Antes de contribuir

Abra uma Issue descrevendo a proposta antes de realizar alterações significativas.

## Princípio fundamental

Toda funcionalidade deve responder à pergunta:

> Isso ajuda o estudante a aprender ou apenas automatiza uma tarefa?

O Luminous pretende utilizar tecnologia para fortalecer o aprendizado, e não eliminar o processo de raciocínio do estudante.

## Conteúdo de terceiros

Não envie ao repositório:

- livros protegidos;
- PDFs obtidos sem autorização;
- credenciais;
- tokens;
- dados de estudantes;
- dados pessoais reais;
- materiais pertencentes a plataformas educacionais de terceiros.

## Código

Mudanças futuras deverão ser:

- documentadas;
- revisáveis;
- seguras;
- acessíveis sempre que aplicável;
- compatíveis com os princípios do projeto.
